Concepts

Checkpoint: A saved local state of a process.

Consistent Global State: A cut where no message is received but never sent (no orphan messages).

Recovery Line: The most recent consistent set of checkpoints the system can roll back to.

Domino Effect: Cascading rollbacks across processes due to uncoordinated checkpointing.
